## 🚀 Featured Projects

### 🐶 PawSense AI — Dog Behaviour Analysis & Pet Care Recommendation System

An AI-powered application that classifies dog behaviour and provides personalized pet-care recommendations.

- Developed a MobileNetV2-based CNN to classify eight dog behaviours from images.
- Designed recommendations for pet health, food, and toys.
- Integrated a Llama 3 chatbot using Ollama and FastAPI REST APIs.

**Tech Stack:** Python, TensorFlow, MobileNetV2, OpenCV, FastAPI, Llama 3, Ollama

### 🎯 AI-Based Interview Preparation Assistant

An intelligent interview preparation platform that helps candidates understand job requirements and prepare for interviews.

- Analyses PDF-based job descriptions.
- Predicts job roles and extracts relevant skills using ML and NLP.
- Generates personalized interview recommendations and chatbot-based guidance.

**Tech Stack:** Python, Flask, Scikit-learn, NLP, TF-IDF, Logistic Regression, PyPDF2

### 🤟 TalkHands — Sign Language Converter

A computer-vision application that converts recognized hand gestures into text and speech.

- Developed a CNN-based hand gesture recognition system.
- Used OpenCV for image processing and gesture recognition.
- Integrated text and speech output to support communication.

**Tech Stack:** Python, CNN, Computer Vision, OpenCV

### 🔄 ETL Pipeline Using Apache Airflow

An automated data pipeline for extracting, transforming, and loading employee data into PostgreSQL.

- Orchestrated workflow execution using Airflow DAGs.
- Used Pandas for data processing.
- Containerized the pipeline environment with Docker.

**Tech Stack:** Python, Apache Airflow, PostgreSQL, Pandas, Docker

### ⚙️ CI/CD Pipeline Using Jenkins & Docker

An automated continuous integration and delivery workflow for a Flask application.

- Configured a Jenkins pipeline for application delivery.
- Containerized the application using Docker.
- Integrated Pytest for automated pre-deployment testing.

**Tech Stack:** Python, Flask, Jenkins, Docker, Pytest
